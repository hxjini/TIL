## Windows 보조 프로그램

**메모장**

- **텍스트(TXT) 형식의 문서**만 열거나 저장할 수 있음
- **그림, 차트 등의 OLE 개체**를 **삽입할 수 없음**
- ANSI, 유니코드, UTF-8 등의 인코딩 형식으로 저장할 수 있음
- 문서의 첫 행 맨 왼쪽에 대문자로 .LOG라고 입력하면 메모장을 열 때마다 현재의 시간과 날짜를 문서 맨 끝에 표시함

**그림판**

- **기본 저장 형식은 PNG**이며, BMP, GIF, TIF, JPG, HEIC, 형식으로 저장할 수 있음
- 그림판에서 편집한 그림을 다른 문서에 붙여넣거나 Windows 바탕 화면의 배경으로 사용할 수 있음
- **Shift를 누를 상태**에서는 수평선, 수직선, 45°의 대각선, 정사각형, 정원을 그릴 수 있음
- 그림의 크기 조정 및 회전, 대칭 이동 등의 편집이 가능함
